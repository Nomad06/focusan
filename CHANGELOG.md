## [1.0.0] — 2026-05-28

Initial Chrome Web Store release.

### Features
- Block any website at the network layer using Chrome's `declarativeNetRequest`.
- Schedules: work hours, weekdays, weekends, custom day/time rules, overnight ranges.
- Daily limits: cap visits or minutes per site.
- Pomodoro focus sessions (blocklist or whitelist mode) with calm timer and bell.
- Temporary allowances with explicit duration.
- Local statistics, streaks, achievements — no telemetry, no remote sync of usage data.
- English and Russian interface.
- Two themes: Kuro (dark) and Shiro (light).

### Privacy
- No data leaves the browser. No analytics, no external services.
- Privacy policy: <https://nomad06.github.io/focusan/>
